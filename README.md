# 双语音声工作流 v1.2.0

基于 PyQt6 的三步式配音工作流工具：**字幕提取 → 语音合成 → 音频混音**，一键批量处理，输出双语配音视频/音频。

## 功能概览

| 步骤 | 功能 | 说明 |
|---|---|---|
| 步骤1 | 字幕提取 | 调用 faster-whisper（infer.exe）从视频/音频中提取 LRC 字幕 |
| 步骤2 | 语音生成 | 使用 Edge TTS / API 将字幕文本合成为配音片段 |
| 步骤3 | 音频混音 | 将配音混入原始音频，支持声道定位、起拍对齐、内容对齐 |

## 运行环境

- Windows 10+
- Python 3.9+
- ffmpeg（需在 PATH 中）

## 安装

```bash
pip install PyQt6 pydub numpy edge-tts requests
```

## 首次启动

1. 运行 `python main.py`
2. 在弹出的配置对话框中指定 **faster-whisper 项目路径**（`infer.exe` 所在目录）和 **工作区目录**
3. 点击"确定"后进入主界面

## 使用流程

### 单个任务

1. 拖拽视频/音频文件或文件夹到任务列表，或点击 **+ 添加视频/音频** / **+ 添加文件夹**
2. 程序自动识别同目录字幕文件并关联

### 跳过步骤

- **+ 添加字幕**：直接指定字幕文件，跳过步骤1
- **+ 添加配音**：直接指定配音目录（含 .wav 文件），跳过步骤2
- **自动检测**：添加任务时自动检测已存在的字幕、配音文件和双语输出，跳过对应完成步骤

### 批量执行

- 支持 **按任务**（每个任务依次执行全部步骤）和 **按步骤**（所有任务先跑步骤1，再步骤2，再步骤3）
- 步骤1 批量模式：一次加载模型处理所有文件
- 步骤3 并行模式：多线程同时混音多个任务（可在混音配置中设置线程数）

## 配置面板

### 字幕配置（步骤1，通过 **字幕配置...** 按钮打开）

| 参数 | 说明 |
|---|---|
| 推理设备 | auto / cpu / cuda |
| 计算精度 | float32 / float16 / int8 |
| 字幕格式 | lrc / srt / vtt |
| VAD 阈值 | 语音活动检测灵敏度 |
| 最小静音/语音时长 | 控制段落切分粒度 |
| 段落合并 | 合并短片段，设置最大间隔和时长 |

### TTS 配置（步骤2，通过 **TTS 配置...** 按钮打开）

| 参数 | 说明 |
|---|---|
| TTS 模式 | Edge TTS（免费在线）/ API（自定义服务器） |
| 声音 | zh-CN-XiaoxiaoNeural 等 20+ 中文声音 |
| 语速 / 音量 | 百分比调节 |
| 并发线程 | Edge 模式下的并行合成数（默认 5） |
| 批量 API | 单次请求发送多个文本，减少网络开销 |
| 缓存信息 | 显示当前缓存条数、总大小和累计复用次数 |
| 清除缓存 | 一键删除所有 TTS 音频缓存，释放磁盘空间 |

### 混音配置（步骤3，通过 **混音配置...** 按钮打开）

| 参数 | 说明 |
|---|---|
| 音量 | 配音相对原音频的音量偏移（dB） |
| 自动音量 | fixed（匹配原音频 RMS 响度）/ auto（逐帧动态匹配）/ off（纯固定增益） |
| 声道检测 | 自动检测配音在原音频中的方位（左/中/右） |
| 起始对齐 | 跳过配音片段的静音起始部分，对齐到原音频起拍点 |
| 内容对齐 | 用原音频人声起始点纠正字幕时间戳误差 |
| GPU 加速 | 使用 NVENC 硬件编码导出 |
| 导出目录 | 自定义输出路径（默认输出到源文件目录下的 `双语/` 文件夹） |
| 线程数 | 批量混音时的并行任务数 |

## 打包发布

```bash
pyinstaller 双语音声工作流.spec
```

## 音频缓存

TTS 合成结果基于 **文本内容 + 声音模型** 进行 MD5 去重缓存（SQLite + 本地音频文件），相同字幕内容不会重复合成。缓存位于 `resources/tts_audio_cache/`。

可通过 **TTS 配置 → 清除缓存** 按钮一键清理，或手动删除 `resources/tts_audio_cache/` 目录和 `resources/configs/tts_audio_cache.db`。

## 变更记录

### v1.2.0
- TTS 配置面板新增缓存管理：显示缓存大小和复用统计，支持一键清除
- 修复 Edge TTS 合成后临时 .mp3 文件泄漏（每片段浪费双份磁盘空间）
- 修复 `auto_volume` 动态音量模式因字符串不匹配完全失效的问题
- 修复全部流程完成后偶发闪退（重命名函数未处理跨盘符 ValueError）
- 修复 SQLite 连接漏关、全局缓存无限增长、任务状态不持久化等问题
- 优化混音内存占用（64bit→32bit，消除中间副本，内存减半）
- 优化启动速度（合并冗余 subprocess 调用）
- 任务列表百分比移至文件名最前，方便按进度排序
- 清理死代码、配置残留，添加 .gitignore

### v1.1.0
- 任务结构简化：移除 `workspace/<timestamp>/` 中间目录，语音文件直接存于 `workspace/<字幕MD5>/`
- 添加任务时自动检测已生成的语音和混音文件，自动跳过已完成步骤
- 批量执行进度条修复，三个步骤均可实时显示进度
- TTS 缓存与日志路径统一到 `resources/` 目录
- 全局屏蔽 subprocess 控制台窗口弹出
- 应用图标设置
- 新增 PyInstaller 打包配置
- 修复打包后 `sys` 未导入导致的启动崩溃
- Edge TTS 单条生成添加 15 秒超时，防止网络卡住导致进度永久阻塞
- Edge TTS 超时/异常后自动重试（最多 3 次，间隔 1 秒）
- 修复 `subprocess.Popen` 猴子补丁与 `asyncio` 冲突（改用类继承方式）
- 新增文件夹拖放导入（"+ 添加文件夹"按钮，自动递归扫描音频和字幕）
- 新增混音完成后自动为源文件夹添加"双语-"前缀（混音配置中可开关）
- 修复文件夹重命名时机（同文件夹所有任务完成后才重命名，避免混音中断）
- 修复重命名目标层级（重命名拖入的根文件夹而非音频文件父目录）
- 修复文件夹扫描不支持 `.wav`/`.wma` 格式的问题
